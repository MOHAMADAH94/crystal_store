الرابط الأساسي (Base URL)

الرابط الأساسي:
https://www.crystal4card.com/api

المصادقة (Authentication)

1. Token Authentication

للحصول على Token:

  1. سجل حساب جديد: POST /auth/register/
  2. أو سجل الدخول: POST /auth/login/
  3. ستحصل على token في الاستجابة
  4. أضفه في header Authorization
Authorization: Token <your_token_here>

2. API Key Authentication

للحصول على API Key:

  • اتصل بالمسؤول لإنشاء API Key لك
  • أو استخدم POST /api-keys/ مع Token
X-API-Key: <your_api_key_here>
⚠️ مهم: احفظ API Key فوراً - لن تتمكن من رؤيته مرة أخرى!

إنشاء طلب (Create Order)

POST /orders/create_order/
إنشاء طلب جديد
Authentication Required: Token or API Key

Request Body:

Field Type Required Description
package_id integer Required معرف الباقة (من GET /packages/)
quantity decimal Required الكمية (يدعم العدد العشري إذا كان المنتج يسمح بذلك)
gamer_id string Required معرف اللاعب/المستخدم في اللعبة
custom_quantity decimal Optional الكمية المخصصة للباقات المخصصة
{ "package_id": 1, "quantity": 1.0, "gamer_id": "player123" }

Response (201 Created):

{ "id": 123, "message": "تم إنشاء الطلب بنجاح", "updated_balance": "100.0000", "order_date": "2026-02-07T10:30:00Z", "is_finished": true }

Error Response (400):

{ "error": "الرصيد غير كافي", "required_balance": "10.0000", "available_balance": "5.0000", "shortage": "5.0000" }

تتبع الطلبات (Get Orders)

GET /orders/
الحصول على جميع الطلبات
ملاحظة مهمة: يتم تحديث حالة الطلبات تلقائياً من API المزود عند جلب الطلبات. لا حاجة لاستدعاء endpoint منفصل لتحديث الحالة.

Response (200 OK):

{ "count": 10, "next": null, "previous": null, "results": [ { "id": 123, "user": { "id": 1, "username": "user123" }, "order_date": "2026-02-07T10:30:00Z", "is_finished": true, "details": [ { "id": 456, "package": { "id": 1, "name": "100 Diamond" }, "price": "10.0000", "final_price": "10.1000", "gamer_id": "player123", "quantity": "1.0000", "status": "done", "response": "تم إرسال الطلب بنجاح" } ] } ] }

حالات الطلب (Order Status)

حالات الطلب:

  • pending - قيد المعالجة (الطلب تم إرساله للمزود وهو قيد المعالجة)
  • done - مكتمل (تم تنفيذ الطلب بنجاح)
  • rejected - مرفوض (تم رفض الطلب من المزود)

ملاحظة: يتم تحديث حالة الطلب تلقائياً من API المزود عند جلب الطلبات باستخدام GET /orders/. لا حاجة لاستدعاء endpoint منفصل.

ملاحظة: الحقل response يحتوي على ملاحظات أو رسالة من API المزود.

أمثلة (Examples)

مثال 1: الحصول على الباقات (cURL)

curl -X GET https://www.crystal4card.com/api/packages/?product=1

مثال 2: إنشاء طلب (cURL)

curl -X POST https://www.crystal4card.com/api/orders/create_order/ \ -H "Authorization: Token YOUR_TOKEN_HERE" \ -H "Content-Type: application/json" \ -d '{ "package_id": 1, "quantity": 1.0, "gamer_id": "player123" }'

مثال 3: تتبع الطلبات (cURL)

curl -X GET https://www.crystal4card.com/api/orders/ \ -H "Authorization: Token YOUR_TOKEN_HERE"

مثال 1: الحصول على الباقات (JavaScript)

fetch('https://www.crystal4card.com/api/packages/?product=1') .then(response => response.json()) .then(data => console.log(data)) .catch(error => console.error('Error:', error));

مثال 2: إنشاء طلب (JavaScript)

fetch('https://www.crystal4card.com/api/orders/create_order/', { method: 'POST', headers: { 'Authorization': 'Token YOUR_TOKEN_HERE', 'Content-Type': 'application/json' }, body: JSON.stringify({ package_id: 1, quantity: 1.0, gamer_id: 'player123' }) }) .then(response => response.json()) .then(data => console.log(data)) .catch(error => console.error('Error:', error));

مثال 3: تتبع الطلبات (JavaScript)

fetch('https://www.crystal4card.com/api/orders/', { headers: { 'Authorization': 'Token YOUR_TOKEN_HERE' } }) .then(response => response.json()) .then(data => { // data.results contains array of orders data.results.forEach(order => { order.details.forEach(detail => { console.log(`Order ${detail.id}: ${detail.status} - ${detail.response}`); }); }); }) .catch(error => console.error('Error:', error));

مثال 1: الحصول على الباقات (Python)

import requests url = "https://www.crystal4card.com/api/packages/" params = {"product": 1} response = requests.get(url, params=params) print(response.json())

مثال 2: إنشاء طلب (Python)

import requests url = "https://www.crystal4card.com/api/orders/create_order/" headers = { "Authorization": "Token YOUR_TOKEN_HERE", "Content-Type": "application/json" } data = { "package_id": 1, "quantity": 1.0, "gamer_id": "player123" } response = requests.post(url, json=data, headers=headers) print(response.json())

مثال 3: تتبع الطلبات (Python)

import requests url = "https://www.crystal4card.com/api/orders/" headers = { "Authorization": "Token YOUR_TOKEN_HERE" } response = requests.get(url, headers=headers) data = response.json() # Print order statuses for order in data['results']: for detail in order['details']: print(f"Order {detail['id']}: {detail['status']} - {detail['response']}")

معالجة الأخطاء (Error Handling)

رموز HTTP الشائعة:

  • 200 OK - نجح الطلب
  • 201 Created - تم إنشاء المورد بنجاح
  • 400 Bad Request - بيانات الطلب غير صحيحة
  • 401 Unauthorized - المصادقة مطلوبة أو غير صحيحة
  • 404 Not Found - المورد غير موجود
  • 500 Internal Server Error - خطأ في الخادم
