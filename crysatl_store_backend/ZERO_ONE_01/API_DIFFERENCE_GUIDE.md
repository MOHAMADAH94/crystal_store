# دليل الفرق بين نوعي المتاجر

## 📋 نظرة عامة

هناك **نوعان مختلفان** من المتاجر في النظام:

### 1️⃣ **المتاجر التي تستخدم منتجاتك** (تأتي إليك)
- هم يريدون **استخدام منتجاتك** و**إنشاء طلبات على حسابهم** في موقعك
- **يستخدمون API Key من موقعك**
- **يتم خصم المبلغ من رصيدهم** في موقعك

### 2️⃣ **المتاجر التي تستخدم منتجاتهم** (تذهب إليهم)
- أنت تريد **استخدام منتجاتهم** و**إنشاء طلبات على حسابك** في موقعهم
- **يستخدمون API Key من موقعهم** (يعطونك إياه)
- **يتم خصم المبلغ من رصيدك** في موقعهم

---

## 1️⃣ المتاجر التي تستخدم منتجاتك (تأتي إليك)

### السيناريو:
- متجر يريد **استخدام منتجاتك**
- يريد **إنشاء طلبات على حسابه** في موقعك
- **يتم خصم المبلغ من رصيده** في موقعك

### الخطوات:

#### 1. المتجر يسجل حساب في موقعك
```python
POST /api/auth/register/
{
  "username": "store_name",
  "email": "store@example.com",
  "password": "password"
}
```

#### 2. أنت تضيف رصيد لحسابه
- اذهب إلى `/admin/accounts/userprofile/`
- ابحث عن المستخدم
- أضف رصيد لحسابه

#### 3. المتجر ينشئ API Key من موقعك
```python
POST /api/api-keys/
Headers: Authorization: Token {token}
{
  "name": "My Store API Key"
}
```

#### 4. المتجر يستخدم API Key لإنشاء الطلبات
```python
POST /api/orders/create_order/
Headers: X-API-Key: {api_key_from_your_site}
{
  "package_id": 1,
  "quantity": 5,
  "gamer_id": "player123"
}
```

### النتيجة:
- ✅ يتم إنشاء الطلب على **حساب المتجر** في موقعك
- ✅ يتم خصم المبلغ من **رصيد المتجر** في موقعك
- ✅ يتم معالجة الطلب في موقعك

### النموذج المستخدم:
- **`APIKey`** model
- كل API Key مرتبط بمستخدم في موقعك
- المستخدم يستخدم API Key لإنشاء طلبات على حسابه

---

## 2️⃣ المتاجر التي تستخدم منتجاتهم (تذهب إليهم)

### السيناريو:
- أنت تريد **استخدام منتجات متجر خارجي**
- تريد **إنشاء طلبات على حسابك** في موقعهم
- **يتم خصم المبلغ من رصيدك** في موقعهم

### الخطوات:

#### 1. المتجر الخارجي يعطيك API Key
- المتجر الخارجي يعطيك **API Key من موقعهم**
- مثال: `external_store_api_key_12345`

#### 2. أنت تضيف المتجر في لوحة التحكم
- اذهب إلى `/admin/api/externalstore/`
- اضغط "Add External Store"
- أدخل:
  - **اسم المتجر**: "متجر الألعاب"
  - **المستخدم**: **اختر حسابك** (الحساب الذي تريد استخدامه)
  - **API Key الخاص بهم**: `external_store_api_key_12345` (الذي أعطاك إياه المتجر)
  - **Base URL**: `https://external-store.com`

#### 3. أنت تستخدم API Key لإرسال طلبات
```python
POST https://external-store.com/api/external/order/
Headers: X-API-Key: external_store_api_key_12345
{
  "package_id": 1,
  "quantity": 5,
  "gamer_id": "player123"
}
```

### النتيجة:
- ✅ يتم إنشاء الطلب على **حسابك** في موقعهم
- ✅ يتم خصم المبلغ من **رصيدك** في موقعهم
- ✅ يتم معالجة الطلب في موقعهم

### النموذج المستخدم:
- **`ExternalStore`** model
- كل متجر خارجي مرتبط بمستخدم في موقعك
- أنت تستخدم API Key من موقعهم لإرسال طلبات

---

## 📊 جدول المقارنة

| الميزة | المتاجر التي تستخدم منتجاتك | المتاجر التي تستخدم منتجاتهم |
|--------|---------------------------|---------------------------|
| **الاتجاه** | يأتون إليك | تذهب إليهم |
| **API Key** | من موقعك | من موقعهم |
| **النموذج** | `APIKey` | `ExternalStore` |
| **المستخدم** | حساب المتجر في موقعك | حسابك في موقعهم |
| **الرصيد** | من رصيد المتجر في موقعك | من رصيدك في موقعهم |
| **Endpoint** | `/api/orders/create_order/` | `/api/external/order/` |
| **الموقع** | موقعك | موقعهم |

## 🔄 مثال عملي

### المثال 1: متجر يستخدم منتجاتك

**السيناريو:**
- متجر "أحمد للألعاب" يريد استخدام منتجاتك
- لديه حساب في موقعك: `ahmed_store`
- لديه رصيد: 1000.00

**الخطوات:**
1. أحمد يسجل في موقعك
2. أنت تضيف رصيد لحسابه
3. أحمد ينشئ API Key من موقعك: `your_api_key_abc123`
4. أحمد يستخدم API Key:
   ```python
   POST http://your-site.com/api/orders/create_order/
   Headers: X-API-Key: your_api_key_abc123
   ```
5. يتم خصم المبلغ من رصيد أحمد في موقعك

**النموذج:** `APIKey` في موقعك

---

### المثال 2: أنت تستخدم منتجات متجر خارجي

**السيناريو:**
- متجر "محمد للألعاب" لديه منتجات
- أنت تريد استخدام منتجاته
- لديك حساب في موقعه: `your_account`
- لديك رصيد: 500.00

**الخطوات:**
1. محمد يعطيك API Key من موقعه: `mohamed_api_key_xyz789`
2. أنت تضيف المتجر في لوحة التحكم:
   - **المستخدم**: `your_account` (حسابك في موقع محمد)
   - **API Key**: `mohamed_api_key_xyz789`
3. أنت تستخدم API Key:
   ```python
   POST https://mohamed-store.com/api/external/order/
   Headers: X-API-Key: mohamed_api_key_xyz789
   ```
4. يتم خصم المبلغ من رصيدك في موقع محمد

**النموذج:** `ExternalStore` في موقعك

## 🎯 الخلاصة

### للمتاجر التي تستخدم منتجاتك:
- ✅ يستخدمون **`APIKey`** من موقعك
- ✅ ينشئون طلبات على **حسابهم** في موقعك
- ✅ يتم خصم المبلغ من **رصيدهم** في موقعك
- ✅ Endpoint: `/api/orders/create_order/`

### للمتاجر التي تستخدم منتجاتهم:
- ✅ تستخدم **`ExternalStore`** في موقعك
- ✅ تستخدم **API Key من موقعهم**
- ✅ تنشئ طلبات على **حسابك** في موقعهم
- ✅ يتم خصم المبلغ من **رصيدك** في موقعهم
- ✅ Endpoint: `/api/external/order/` (في موقعهم)

## 📝 ملاحظات مهمة

### 1. APIKey vs ExternalStore

**APIKey:**
- للمتاجر التي **تأتي إليك**
- API Key **من موقعك**
- الطلبات على **حسابهم** في موقعك

**ExternalStore:**
- للمتاجر التي **تذهب إليهم**
- API Key **من موقعهم**
- الطلبات على **حسابك** في موقعهم

### 2. الاتجاه

- **APIKey**: هم يستخدمونك → يأتون إليك
- **ExternalStore**: أنت تستخدمهم → تذهب إليهم

### 3. الرصيد

- **APIKey**: من رصيدهم في موقعك
- **ExternalStore**: من رصيدك في موقعهم

## 🔧 الإعداد

### إعداد APIKey (للمتاجر التي تستخدم منتجاتك):
1. المتجر يسجل في موقعك
2. أنت تضيف رصيد لحسابه
3. المتجر ينشئ API Key من `/api/api-keys/`
4. المتجر يستخدم API Key

### إعداد ExternalStore (للمتاجر التي تستخدم منتجاتهم):
1. المتجر الخارجي يعطيك API Key
2. أنت تضيف المتجر في `/admin/api/externalstore/`
3. تربط المتجر بحسابك
4. أنت تستخدم API Key لإرسال طلبات
