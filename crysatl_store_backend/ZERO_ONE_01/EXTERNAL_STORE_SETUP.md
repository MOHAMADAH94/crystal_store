# دليل إعداد المتاجر الخارجية - الربط بحساب مستخدم

## 📋 نظرة عامة

الآن يمكنك ربط **المتاجر الخارجية بحساب مستخدم** في موقعك. عندما يستخدم المتجر الخارجي API Key الخاص به، سيتم:
- ✅ إنشاء الطلبات على حساب المستخدم المرتبط بالمتجر
- ✅ خصم المبلغ من رصيد المستخدم تلقائياً
- ✅ معالجة الطلب بشكل كامل

---

## 🚀 الخطوات العملية

### الخطوة 1: إنشاء حساب للمتجر

1. سجل المتجر في موقعك كـ **مستخدم عادي**
2. أضف رصيد لحسابه من لوحة التحكم

### الخطوة 2: إضافة متجر خارجي وربطه بالمستخدم

1. اذهب إلى `/admin/api/externalstore/`
2. اضغط "Add External Store"
3. أدخل:
   - **اسم المتجر**: اسم المتجر (مثل "متجر الألعاب")
   - **المستخدم**: **اختر المستخدم الذي أنشأته للمتجر** ⭐ (هذا مهم جداً!)
   - **API Key الخاص بهم**: API Key الذي يعطيك إياه المتجر الخارجي
   - **Base URL**: رابط المتجر الخارجي
   - **Webhook URL** (اختياري): رابط لإرسال إشعارات الطلبات
4. احفظ

### الخطوة 3: المتجر يستخدم API Key

المتجر الآن يستخدم API Key الخاص به لإرسال طلبات:

```python
import requests

# API Key الذي أعطاه المتجر لك
STORE_API_KEY = "store_api_key_12345"
BASE_URL = "http://your-domain.com"

# إرسال طلب
response = requests.post(
    f'{BASE_URL}/api/external/order/',
    headers={
        'X-API-Key': STORE_API_KEY,
        'Content-Type': 'application/json'
    },
    json={
        'package_id': 1,      # ID الباقة
        'quantity': 5,         # الكمية
        'gamer_id': 'player123' # معرف اللاعب
    }
)

result = response.json()
print(result)
# {
#   "id": 123,
#   "message": "تم إنشاء الطلب بنجاح",
#   "updated_balance": "950.00",
#   "order_date": "2024-01-11T12:00:00Z",
#   "is_finished": true,
#   "store_name": "متجر الألعاب"
# }
```

## 🔄 كيف يعمل النظام؟

### عند إرسال طلب من متجر خارجي:

1. **التحقق من API Key**: النظام يتحقق من صحة API Key
2. **تحديد المتجر**: يتم العثور على `ExternalStore` المرتبط بـ API Key
3. **تحديد المستخدم**: يتم استخدام المستخدم المرتبط بالمتجر (`store.user`)
4. **حساب السعر**: يتم حساب السعر حسب نوع الباقة ومستوى المستخدم
5. **التحقق من الرصيد**: يتم التحقق من وجود رصيد كافي في حساب المستخدم
6. **خصم الرصيد**: يتم خصم المبلغ من رصيد المستخدم المرتبط بالمتجر تلقائياً
7. **إنشاء الطلب**: يتم إنشاء الطلب على حساب المستخدم
8. **إرسال Webhook**: يتم إرسال إشعارات للمتاجر الخارجية الأخرى (إذا تم إعدادها)

## 📊 مثال كامل

### السيناريو:
- لديك متجر خارجي اسمه "متجر الألعاب"
- المتجر لديه حساب في موقعك: `store_user`
- المتجر لديه رصيد: 1000.00
- المتجر يعطيك API Key: `store_api_key_12345`

### الإعداد:

1. **في لوحة التحكم:**
   - اذهب إلى `/admin/api/externalstore/`
   - أنشئ متجر خارجي:
     - **اسم المتجر**: "متجر الألعاب"
     - **المستخدم**: `store_user` ⭐
     - **API Key الخاص بهم**: `store_api_key_12345`
     - **Base URL**: `https://store-example.com`

### الاستخدام:

```python
import requests

# المتجر يستخدم API Key الخاص به
response = requests.post(
    'http://your-domain.com/api/external/order/',
    headers={'X-API-Key': 'store_api_key_12345'},
    json={
        'package_id': 1,
        'quantity': 5,
        'gamer_id': 'player123'
    }
)

print(response.json())
# {
#   "id": 123,
#   "message": "تم إنشاء الطلب بنجاح",
#   "updated_balance": "950.00",  # الرصيد بعد الخصم
#   "order_date": "2024-01-11T12:00:00Z",
#   "is_finished": true,
#   "store_name": "متجر الألعاب"
# }
```

**النتيجة:**
- ✅ تم إنشاء الطلب على حساب `store_user`
- ✅ تم خصم 50.00 من رصيد `store_user`
- ✅ الرصيد الجديد: 950.00

## ⚠️ ملاحظات مهمة

### 1. ربط المستخدم إلزامي

- **يجب ربط المتجر بمستخدم** قبل استخدام API
- إذا لم يكن المتجر مرتبطاً بمستخدم، سيتم رفض الطلب

### 2. الرصيد

- **يجب أن يكون لدى المستخدم رصيد كافي**
- إذا كان الرصيد غير كافي، سيتم رفض الطلب مع تفاصيل الرصيد

### 3. API Key

- **API Key في ExternalStore** هو API Key الذي يعطيك إياه المتجر الخارجي
- **ليس** API Key الذي تنشئه في `APIKey` model

---

## 🔐 الفرق بين APIKey و ExternalStore

| APIKey | ExternalStore |
|--------|---------------|
| **للمستخدمين** الذين يريدون استخدام API الخاص بك | **للمتاجر الخارجية** التي تريد الربط معك |
| أنت تنشئه للمستخدم | المتجر الخارجي يعطيك API Key الخاص به |
| يستخدمونه للوصول إلى API | يستخدمونه لإرسال طلبات إليك |
| مرتبط بمستخدم | مرتبط بمستخدم (الآن) |
| يستخدم `/api/orders/create_order/` | يستخدم `/api/external/order/` |

---

## 📝 Endpoints

### للمستخدمين (APIKey):

```bash
POST /api/orders/create_order/
Headers: X-API-Key: {api_key}
Body: {
  "package_id": 1,
  "quantity": 5,
  "gamer_id": "player123"
}
```

### للمتاجر الخارجية (ExternalStore):

```bash
POST /api/external/order/
Headers: X-API-Key: {store_api_key}
Body: {
  "package_id": 1,
  "quantity": 5,
  "gamer_id": "player123"
}
```

**الفرق:**
- نفس البيانات
- نفس النتيجة (إنشاء طلب وخصم رصيد)
- لكن `external_order` يستخدم المستخدم المرتبط بـ `ExternalStore`

## ❓ الأسئلة الشائعة

### س: لماذا أحتاج ربط المتجر بمستخدم؟

**ج:** لأن الطلبات تُنشأ على حساب المستخدم، ويتم خصم المبلغ من رصيده. بدون ربط المستخدم، لا يمكن إنشاء الطلبات.

### س: ماذا يحدث إذا لم أربط المتجر بمستخدم؟

**ج:** سيتم رفض الطلب مع رسالة خطأ: "المتجر غير مرتبط بمستخدم"

### س: هل يمكن ربط متجر واحد بعدة مستخدمين؟

**ج:** لا، كل متجر مرتبط بمستخدم واحد فقط.

### س: هل يمكن ربط مستخدم واحد بعدة متاجر؟

**ج:** نعم، يمكن لمستخدم واحد أن يكون مرتبطاً بعدة متاجر خارجية.
