# دليل واضح: الفرق بين نوعي المتاجر

## 🎯 الفرق الأساسي

### 1️⃣ **المتاجر التي تستخدم منتجاتك** (تأتي إليك)
```
المتجر → يستخدم منتجاتك → ينشئ طلبات على حسابه في موقعك
```

### 2️⃣ **المتاجر التي تستخدم منتجاتهم** (تذهب إليهم)
```
أنت → تستخدم منتجاتهم → تنشئ طلبات على حسابك في موقعهم
```

---

## 📊 جدول المقارنة الواضح

| الميزة | المتاجر التي تستخدم منتجاتك | المتاجر التي تستخدم منتجاتهم |
|--------|---------------------------|---------------------------|
| **الاتجاه** | 👉 **يأتون إليك** | 👈 **تذهب إليهم** |
| **من يستخدم ماذا** | هم يستخدمون منتجاتك | أنت تستخدم منتجاتهم |
| **أين يتم إنشاء الطلب** | في موقعك | في موقعهم |
| **من يدفع** | المتجر (من رصيده في موقعك) | أنت (من رصيدك في موقعهم) |
| **النموذج** | `APIKey` | `ExternalStore` |
| **API Key من أين** | من موقعك | من موقعهم |
| **Endpoint** | `/api/orders/create_order/` | `/api/external/order/` (في موقعهم) |
| **الموقع** | موقعك | موقعهم |

## 1️⃣ المتاجر التي تستخدم منتجاتك (تأتي إليك)

### الوصف:
- متجر يريد **شراء منتجاتك**
- يريد **إنشاء طلبات على حسابه** في موقعك
- **يتم خصم المبلغ من رصيده** في موقعك

### مثال:
- متجر "أحمد للألعاب" يريد شراء منتجاتك
- لديه حساب في موقعك: `ahmed_store`
- لديه رصيد: 1000.00

### الخطوات:

#### 1. المتجر يسجل في موقعك
```python
POST http://your-site.com/api/auth/register/
{
  "username": "ahmed_store",
  "email": "ahmed@example.com",
  "password": "password123"
}
```

#### 2. أنت تضيف رصيد لحسابه
- اذهب إلى `/admin/accounts/userprofile/`
- ابحث عن `ahmed_store`
- أضف رصيد: 1000.00

#### 3. المتجر ينشئ API Key من موقعك
```python
POST http://your-site.com/api/api-keys/
Headers: Authorization: Token {token}
{
  "name": "Ahmed Store API Key"
}

# Response:
{
  "key": "your_site_api_key_abc123",
  "name": "Ahmed Store API Key"
}
```

#### 4. المتجر يستخدم API Key لإنشاء الطلبات
```python
POST http://your-site.com/api/orders/create_order/
Headers: X-API-Key: your_site_api_key_abc123
{
  "package_id": 1,
  "quantity": 5,
  "gamer_id": "player123"
}

# Response:
{
  "id": 123,
  "message": "تم إنشاء الطلب بنجاح",
  "updated_balance": "950.00",  # رصيد أحمد بعد الخصم
  "is_finished": true
}
```

### النتيجة:
- ✅ تم إنشاء الطلب على **حساب أحمد** في موقعك
- ✅ تم خصم 50.00 من **رصيد أحمد** في موقعك
- ✅ الرصيد الجديد: 950.00

### النموذج المستخدم:
- **`APIKey`** في موقعك
- كل API Key مرتبط بمستخدم في موقعك

## 2️⃣ المتاجر التي تستخدم منتجاتهم (تذهب إليهم)

### الوصف:
- أنت تريد **شراء منتجات متجر خارجي**
- تريد **إنشاء طلبات على حسابك** في موقعهم
- **يتم خصم المبلغ من رصيدك** في موقعهم

### مثال:
- متجر "محمد للألعاب" لديه منتجات
- أنت تريد شراء منتجاته
- لديك حساب في موقعه: `your_account`
- لديك رصيد: 500.00

### الخطوات:

#### 1. المتجر الخارجي يعطيك API Key
- محمد يعطيك API Key من موقعه: `mohamed_site_api_key_xyz789`
- هذا API Key من **موقع محمد**، ليس من موقعك

#### 2. أنت تضيف المتجر في لوحة التحكم
- اذهب إلى `/admin/api/externalstore/`
- اضغط "Add External Store"
- أدخل:
  - **اسم المتجر**: "محمد للألعاب"
  - **المستخدم**: `your_account` (حسابك في موقع محمد)
  - **API Key الخاص بهم**: `mohamed_site_api_key_xyz789` (من موقع محمد)
  - **Base URL**: `https://mohamed-store.com`

#### 3. أنت تستخدم API Key لإرسال طلبات
```python
POST https://mohamed-store.com/api/external/order/
Headers: X-API-Key: mohamed_site_api_key_xyz789
{
  "package_id": 1,
  "quantity": 5,
  "gamer_id": "player123"
}

# Response:
{
  "id": 456,
  "message": "تم إنشاء الطلب بنجاح",
  "updated_balance": "450.00",  # رصيدك في موقع محمد بعد الخصم
  "is_finished": true
}
```

### النتيجة:
- ✅ تم إنشاء الطلب على **حسابك** في موقع محمد
- ✅ تم خصم 50.00 من **رصيدك** في موقع محمد
- ✅ الرصيد الجديد: 450.00

### النموذج المستخدم:
- **`ExternalStore`** في موقعك
- كل متجر خارجي مرتبط بحسابك في موقعهم

## 📝 ملخص سريع

### للمتاجر التي تستخدم منتجاتك:
- ✅ **النموذج**: `APIKey`
- ✅ **API Key**: من موقعك
- ✅ **Endpoint**: `/api/orders/create_order/` (في موقعك)
- ✅ **الرصيد**: من رصيدهم في موقعك
- ✅ **الاتجاه**: يأتون إليك

### للمتاجر التي تستخدم منتجاتهم:
- ✅ **النموذج**: `ExternalStore`
- ✅ **API Key**: من موقعهم
- ✅ **Endpoint**: `/api/external/order/` (في موقعهم)
- ✅ **الرصيد**: من رصيدك في موقعهم
- ✅ **الاتجاه**: تذهب إليهم
